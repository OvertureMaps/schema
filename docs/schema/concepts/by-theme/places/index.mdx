## Overview

The Overture places theme includes more than 50M places and points of interest around the world. The data is sourced from Meta and Microsoft.

## Feature types

The places theme has one feature type:

- `place` is a feature with a Point geometry.

## Theme concepts

### Taxonomy

Overture Places uses a taxonomy with more than 2,000 possible category values.
Each place can provide a primary category, its hierarchy path, and optional alternate categories.
See the place schema reference for the current taxonomy structure and examples.
