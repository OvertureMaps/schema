Typed the functions that take a type as an argument with `TypeForm`, [PEP
747](https://peps.python.org/pep-0747/)'s type for a type expression: `json_schema` and
`assert_json_schema_golden` take `TypeForm[BaseModel]`, `collect_types` takes
`TypeForm[object]`, and `create_model`'s field definitions match pydantic 2.14's; mypy now
rejects a value there that it cannot read as a type expression, which `TypeForm(...)`
around the value fixes.
