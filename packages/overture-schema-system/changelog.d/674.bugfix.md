Fixed `@deprecated(...)` placed under `@no_extra_fields`, another model-constraint
decorator, or `@scoped`: the decorated model now warns on use and is deprecated in JSON
Schema and the Markdown reference, as when `@deprecated` is outermost, instead of warning
once at definition and never again. A subclass of a deprecated model is no longer marked
`"deprecated": true` in JSON Schema, matching runtime, where using the subclass raises no
warning.
