Replaced `filter_models` with `select_models`, which now also applies discovered extensions to the models it selects (pass the raw registry from `discover_models(apply_extensions=False)`): the selector's excludes opt out of extensions (`exclude_any=("extension",)` yields the un-extended models, and passing already-extended input with such an exclusion raises), while includes and type names never strip extension fields. Standalone extension entries are internal merge machinery, hidden unless `include_extension_entries=True` is passed explicitly for introspection.
